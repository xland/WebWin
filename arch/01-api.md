# API 能力清单

框架对外以 JS API 形态提供能力（经 `02-architecture.md` 所述的消息通道调用）。
本清单是框架的能力边界，**会持续扩充**。

## 基础能力（SDK 提供）

| # | 能力 | 备注 |
| --- | --- | --- |
| 1 | 文件读写、删除、创建 | |
| 2 | 剪贴板访问 | |
| 3 | 托盘图标 | |
| 4 | 应用程序多开通知机制 | **应用被多开时**（第二个实例启动）通知已有实例。第二个实例自身的处置（退出 / 继续运行）待定 |
| 5 | 使用系统对话框 | |
| 6 | 阻止应用锁屏 | 阻止系统进入锁屏/休眠 |
| 7 | 访问系统进程 | |
| 8 | 启动子进程（与子进程通信） | 含 stdin/stdout/stderr 管道通信 |
| 9 | 启动 HTTP 服务 | 应用内起本地 HTTP 服务 |
| 10 | 访问屏幕信息 | 显示器、分辨率、DPI 等 |
| 11 | 访问版本信息 | **系统版本 / 框架版本 / 应用版本** 三类 |
| 12 | 目录操作 API | 创建、遍历、删除等 |
| 13 | 访问常用目录 | 音乐、文档、数据目录等 |
| 14 | 访问窗口 | 枚举窗口、向窗口发送消息 |
