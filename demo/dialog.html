选择文件（dialog.openPath）

返回值是 { cancel, data }：data 一律是路径数组， 单选时也只装一个元素。用户点取消时 cancel 为 true —— 取消是正常结果，不会 reject。

选择文件夹（dialog.openPath，type: 'dir'）

type: 'dir' 时只选文件夹，此时 filter 无效（文件夹对话框不接受文件类型）。

保存文件（dialog.savePath）

返回值同样是 { cancel, data }，但这里的 data 是单个路径字符串， 取消时是空串。defaultPath 给完整文件路径时会拆出目录和默认文件名； 给了 filter 的话，第一个过滤器的后缀会自动补上。

消息框（dialog.msgBox）

直接返回用户点了哪个按钮：'ok' | 'cancel' | 'yes' | 'no' | 'abort' | 'retry' | 'ignore'。 icon 可选 info / warn / err / question / stop，btn 可选 ok / okCancel / yesNo / yesNoCancel / retryCancel / abortRetryIgnore。 对话框会模态挂在当前窗口上（属主窗口被禁用，层级正确）。

在文件夹中显示（dialog.itemInFolder）

相当于资源管理器里"打开文件所在的位置"：会打开一个新窗口并选中该文件，没有返回值。
