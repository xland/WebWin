路径基准

相对路径一律以 package.json 所在目录为底（跟 path.resolve() 一致）。 不能用"进程当前目录"当基准 —— GUI 进程没有有意义的 cwd， 而且 Windows 的文件对话框还会悄悄改掉它。

写 / 读 / 追加

默认按 UTF-8 读写。不会自动建父目录 —— 目录不存在就直接报错。

信息 / 权限

access 默认只查存在。权限位是近似的：W_OK 只看只读属性，不查 ACL。

复制 / 改名 / 删除

二进制：base64 与 ArrayBuffer

binary 走共享内存、不进 JSON，没有 base64 那 1/3 膨胀； 但 buffer 只读，且用完必须 release()，不调会一直占着。
