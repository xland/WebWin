系统标识

getOsVer 拿的是真实系统版本（build ≥ 22000 时 versionName 为 win11）。 getCpuId / getDiskId 常用来做机器标识。

语言与配色

getUserLang 是"当前用户"的语言，getOsLang 是"系统"的语言 —— 两者在多用户机器上可能不同。

网卡与 IP

只返回已启用、有 MAC 的网卡，且不含 127.0.0.1 / ::1。

常用目录（os.getPath）

返回该目录的绝对路径。appData 是 漫游的那份（%APPDATA%），不是 Local。 目录被用户改到别处时，返回的是改后的位置。

阻止休眠

preventSleep 会一直阻止系统休眠和关屏，直到调用 stopPreventSleep 或进程退出。 测完记得点 stopPreventSleep。

锁屏事件（os.on）

订阅后按 Win+L 锁屏，再解锁 —— 两次都会收到事件（locked: true / false）。
