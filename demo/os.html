系统标识

getVersion 拿的是真实系统版本（build ≥ 22000 时 versionName 为 win11）。 getCpuId / getDiskId 常用来做机器标识。

语言与配色

'user' 是"当前用户"的语言，'os' 是"系统"的语言 —— 两者在多用户机器上可能不同。

常用目录（os.getPath）

返回该目录的绝对路径。appData 是 漫游的那份（%APPDATA%），不是 Local。 目录被用户改到别处时，返回的是改后的位置。

阻止休眠

preventSleep 会一直阻止系统休眠和关屏，直到调用 stopPreventSleep 或进程退出。 测完记得点 stopPreventSleep。

系统凭据管理器（os.cred*）

存到系统"凭据管理器"的本机那一栏：不随用户配置漫游到域里的其它机器， 只对当前用户可见。值按 UTF-16 原样存，任何字符都能原样往返。
读不到返回 null（不 reject）；删一个本来没有的 key 也不报错。
点完可以去 控制面板 → 凭据管理器 → Windows 凭据 看到这条记录。

锁屏事件（os.on）

订阅后按 Win+L 锁屏，再解锁 —— 两次都会收到事件（locked: true / false）。
