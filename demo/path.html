常量与基准

基准目录是 package.json 所在的目录 —— resolve() / relative() 拿它当底，取代 Node 的 process.cwd()。

组装

join 遇到绝对路径不会重置；resolve 会 —— 它从右往左 找第一个绝对路径就用它。

拆分

输入同时接受 / 和 \，输出统一成 \。

判定与计算

C:foo 不算绝对路径（缺分隔符），C:\foo 才算。

Windows 专属校验（Node 没有）

NUL.txt / COM1.log 在 Windows 上不是文件， 读写会打到设备上；名字末尾的点和空格会被系统悄悄去掉。这些都判非法。

错误

同步抛出，用 try / catch 接。跟 Node 一致。
