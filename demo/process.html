启动子进程（Process.spawn）

返回的是进程对象（Process 实例），输出和退出码都作为它的事件推回。 spawn 是 async：进程是 C++ 侧的 Win32 对象，得等它建好。
监听要紧跟在 await 后面同步挂上 —— spawn 一 resolve 子进程就已经在跑了， 中间再去 await 别的，开头几行输出就丢了。

stderr 与退出码

stdout / stderr 是两条独立的管道，各走各的事件；exit 带子进程的退出码。输出是按一段一段推的，不是等进程结束才一次给。

控制台窗口与 detached

默认不弹控制台窗口，输出照样能收到；传 hide: false 才显示。
默认的子进程会跟着页面一起结束 —— 关掉窗口（或这个 iframe 被移除）时杀掉， 不留孤儿进程。传 detached: true 就不杀：想让它在页面没了之后 继续跑用它（起了记事本之后可以关掉窗口看看）。
