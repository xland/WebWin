读 / 写（regedit.get / set）

键写成一整条，跟 reg.exe 一样；根键那节 HKCU / HKEY_CURRENT_USER 都认，不分大小写。
写的时候键不存在会自动逐层创建。类型按 value 的 JS 类型挑： 字符串 → REG_SZ，数字 → REG_DWORD（32 位放得下） 或 REG_QWORD。
读不到（键或值不存在）返回 null，不 reject。

值类型

读回来的 data 形态跟着 type 走： 字符串 / 数字 / 字符串数组（REG_MULTI_SZ）/ base64（REG_BINARY）。
REG_EXPAND_SZ 里的 %PATH% 这类引用不展开 —— 它是另一个类型，跟 REG_SZ 分开给的。

枚举

listValues 列值名（不含值，要值就 get 逐个读）； listKeys 列下一层的子键名。两者都不递归。

删键

连子键和值一起删（递归）；键本来就不在也不报错。
删的是上面输入框里那个键 —— 别把它指向系统正在用的键。 想看效果就先用上面的按钮写两条值，再回来删。
