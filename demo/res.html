1. 选一个 exe

选完会先复制一份再操作。原因是：exe 正在运行时改不动它自己的资源 （Windows 以映像方式映射，写打开会被拒），而副本没在运行，改得动。
副本统一写在应用自己的目录里，不往源 exe 所在目录落东西 —— 那些目录 常常不可写（Program Files、工具目录），复制会撞「拒绝访问（错误码 5）」， 还会把垃圾留在用户的目录里。
后面所有按钮操作的都是那个副本，不动你的原文件。

2. 版本信息（getInfo）

读的就是 exe 属性窗口「详细信息」那一栏：fileVersion / productVersion（文本 + 数字数组）， 以及 strings 里的 CompanyName / FileDescription / ProductName 等。

3. 列出资源（list）

不传 type 列全部类型。我们的 exe 里就有现成的： webwin.js（整个 SDK）和 default.html，都是 RCDATA 类型。

4. 增 / 查 / 存 / 删

资源名
按顺序点一遍最直观：加进去 → 读出来 → 导出成文件 → 删掉。 删完再 list 一次，那条就没了。

5. 自证：改不了正在运行的 exe

对第 1 步里选的原文件直接 addText —— 会 reject， 报的是「不能修改正在运行的这个 exe 自身…」这种能看懂的话， 而不是一个天书般的 sharing violation。
（原文件要是没在运行，这条就不会失败 —— 那时能改成功，也是对的。）
