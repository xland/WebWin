新建窗口（Win.create）

新窗口加载的还是本页面。窗口关闭后再调用它的方法，会拿到 C++ 返回的错误信息 —— 用 win2.maximize() 验证。 新窗口的事件由本页面的 win2 接收，不会落进新窗口自己的 win。

无边框窗口（Win.create + frame:false）

传的就是 package.json 里那套 window 配置，一个字段都不差：frame: false + resizable: true。 新窗口加载 winFrameless.html —— 标题栏由 data-caption 标注，8 个 resize 把手由 SDK 自动铺。
